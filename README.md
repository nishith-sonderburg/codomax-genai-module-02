# Module 02: Prompt Engineering & AI Productivity Toolkit

**Track:** Generative AI Virtual Internship (Codomax Digital Solutions)  
**Author:** Nishith Jambhulkar  

## Overview
This repository contains the implementation and evaluation of structured prompt engineering techniques and reusable AI productivity workflows for Module 02.

## Key Objectives Covered
1. **Zero-Shot & Few-Shot Prompting:** Designing prompts using explicit roles, contexts, instructions, and output constraints.
2. **Structured Outputs:** Generating JSON-formatted responses for text summarization and ticket classification.
3. **Prompt Evaluation & Debugging:** Comparing baseline prompts against constrained few-shot templates.
4. **AI Productivity Toolkit:** Reusable prompt templates for summarization, professional email drafting, ATS resume optimization, and code debugging.
